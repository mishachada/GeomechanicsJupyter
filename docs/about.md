# About the Teaching Hub

The Teaching Hub curates math and physics resources tailored to SAT preparation and the AP Physics 1 course. Each page is written with classroom deployment in mind and is structured to be remixable for different learning environments.

## Purpose
- Provide a central, open site where instructors can source guided practice.
- Offer students interactive tools that reinforce conceptual understanding.
- Maintain a modular content architecture that supports expansion across subjects.
