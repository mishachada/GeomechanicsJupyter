# Interactive Demos

Explore concept-focused interactives built with accessible, lightweight JavaScript.

- [Central Limit Theorem Simulator](clt-simulator.html) — run sampling experiments and observe the distribution of sample means.
- [Projectile Motion Explorer](projectile-motion.html) — adjust launch conditions and inspect flight-time and range calculations.
