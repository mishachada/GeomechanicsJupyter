## Prompt
For the quadratic function $f(x) = 2x^2 - 5x + k$, the graph of $f$ touches the $x$-axis at exactly one point. What is the value of $k$?

## Choices
A) $\frac{9}{8}$
B) $\frac{49}{8}$
C) $\frac{25}{8}$
D) $\frac{49}{4}$

<details><summary>Solution</summary>
The graph touches the $x$-axis once when the discriminant is zero. Compute $\Delta = b^2 - 4ac = (-5)^2 - 4(2)(k) = 25 - 8k$. Set $\Delta = 0$ to obtain $25 - 8k = 0$, so $k = \tfrac{25}{8}$. The correct choice is **C**.
</details>
